# Chrome Web Store Assets

Generated listing assets for Anton.IA Automation. Upload the PNG files in this folder to the Chrome Web Store listing.

Prepared files:

- `antonia-web-store-icon-128.png`: required store icon.
- `antonia-web-store-small-promo.png`: optional 440 x 280 promotion image.
- `antonia-web-store-marquee.png`: optional 1400 x 560 promotion image.

The required screenshot must be a real capture of the Anton.IA LinkedIn message review dialog. Do not use a promotional graphic as a product screenshot.
